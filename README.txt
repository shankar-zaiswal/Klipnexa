# Klipnexa Studio website

A responsive, static one-page landing website.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or another browser.
3. Internet access is only needed for the optional Google Fonts. The layout itself is local.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new **public** repository named `klipnexa-studio-website`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. GitHub will provide the public website address after deployment.

Alternative: Netlify can host the same static folder for free on its free tier. Check the provider's current plan limits before publishing.
